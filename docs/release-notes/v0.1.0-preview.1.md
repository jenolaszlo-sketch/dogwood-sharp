# DogwoodSharp 0.1.0-preview.1 — release notes

**Release candidate prepared**: 27 November 2026
**Commission**: `DOGWOOD-SHARP-D3-CLOSE-RELEASE-PREP-01`
**Status**: Preview release candidate. Publication is not authorized by these
notes.

## Packages

| Package | Version | Role |
| --- | --- | --- |
| `DogwoodSharp` | `0.1.0-preview.1` | Managed API and three RID-specific Dogwood native image/manifest pairs |
| `DogwoodSharp.CedarSharp` | `0.1.0-experimental.1` | Experimental D3 CedarSharp authorization adapter |
| `CedarSharp` | `1.0.0` | External authorization engine; exact dependency, not repacked |

The `DogwoodSharp.CedarSharp` package depends exactly on
`DogwoodSharp [0.1.0-preview.1]` and `CedarSharp [1.0.0]`. It contains no
native assets of its own. Each package has a matching `.snupkg` symbol package
containing the `net8.0` and `net10.0` PDBs.

## What is included

- D1: pinned Dogwood parsing, version discovery, macro expansion and
  structured diagnostics.
- D2: schema validation, policy lowering, augmented-schema export and frozen
  D1 compatibility.
- D3 experimental: schema-carrying, request-validating CedarSharp evaluation;
  exact per-rule policy identity; clean-Allow enforcement; fail-closed
  diagnostics; trusted temporal/provider runtime paths; package-only JIT and
  NativeAOT consumption.

## Known qualifications

1. **CedarSharp native provenance.** The published `CedarSharp 1.0.0` package
   and its `win-x64`, `linux-x64` and `osx-arm64` native images are verified by
   immutable package and native hashes. The package nuspec commit
   `68ffdafa` is recoverable. The native manifests declare a `sourceCommit`
   that is not recoverable. These notes do not claim that the external native
   can be reproduced from that declared commit.
2. **Windows native metadata.** Same-source/same-lock Windows builds can differ
   only in embedded PE/debug timestamps and the PDB GUID. The exact
   release-candidate SHA-256 is the binding publication identity; normalized
   equality is not a substitute for the exact artifact hash.
3. **Experimental adapter.** `DogwoodSharp.CedarSharp` is an experimental
   surface. Its API may change; it is not part of the stable `DogwoodSharp`
   package's public contract.
4. **Publication pipeline.** `publish.yml` remains a refusal gate. A separate
   owner-authorized publication commission must implement and qualify the
   exact-artifact OIDC publication path before any package is pushed.
