All rows describe the inspected Dogwood revision, not implemented DogwoodSharp
functionality. “Published” identifies an upstream public surface, not a stability
or production-readiness certification. Dependencies include the resolved Cedar
4.11.0 graph recorded in [sources](sources.md).
